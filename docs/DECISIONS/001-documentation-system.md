# Decisión 001

## Título

Adopción del Sistema de Documentación Continua (SDC)

## Fecha

31/07/2026

## Problema

El proyecto dependía demasiado del contexto de las conversaciones, dificultando retomar el desarrollo después de semanas o incorporar nuevos asistentes.

## Decisión

Toda la documentación oficial vivirá dentro del repositorio en la carpeta `/docs`.

Cada Sprint deberá actualizar los documentos correspondientes antes de considerarse finalizado.

## Beneficios

- Menor pérdida de contexto.
- Fácil incorporación de nuevos desarrolladores o asistentes IA.
- Historial técnico del proyecto.
- Mejor mantenimiento a largo plazo.
